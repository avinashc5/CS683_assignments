# Per-kernel hardware counters, M=N=K=1024, pinned core 3.
#
# Measured by bench/perf_stage, which opens the counters with perf_event_open(2) and
# brackets ONLY the kernel call with IOC_ENABLE/IOC_DISABLE. Process startup,
# allocation, the mt19937 fill (~1.2e8 instructions) and the checksum all fall
# outside the counted region. User-mode counts only (exclude_kernel).
#
# 'cold' streams a 64 MiB buffer before the region to evict A/B/C; 'warm' does not.
# The two agree within 2% on every counter, so cache carryover is not a factor here
# (A+B+C = 12 MiB against a 12 MiB L3 -- the kernels stream through it regardless).
#
# Instruction counts cross-checked four ways for simd, all agreeing within 1.4%:
#   region counting (this file) 2.2886e8 | rep-subtraction 2.2923e8
#   perf record per-symbol      2.2940e8 | harness subtraction 2.32e8
#
# L2-miss uses raw event r3f24 (l2_rqsts.miss on Ice/Tiger Lake); verified identical
# to perf's named l2_rqsts.miss.
